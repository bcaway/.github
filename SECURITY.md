# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or confidentiality issue in BCAway, please report it privately to the project security contact:

- Email: kabsek30@bergen.org

**Please do not create a public issue or publicly disclose the vulnerability.**

When reporting a vulnerability, please include:

- A clear description of the vulnerability and affected components.
- Steps to reproduce the issue, including proof-of-concept code or commands where appropriate. Do not include real student or teacher data.
- Any information about the potential impact, such as data that could be exposed or users who could be affected.
- Your preferred contact method and whether you would like to be credited for the report.

## Response Process

- We aim to acknowledge reports within 72 hours.
- We will review and assess reported vulnerabilities as soon as reasonably possible.
- Security issues involving student, teacher, or other confidential information will be prioritized.
- We may contact the reporter for additional information when necessary.
- Remediation and disclosure decisions will be handled by the BCAway maintainers.

## Responsible Disclosure

Please allow the BCAway maintainers reasonable time to investigate and address a reported vulnerability before making information about it public.

If a vulnerability has already been publicly disclosed, please still report it privately so that we can assess its impact and take appropriate action.

## Safe Harbor

Security research conducted in good faith and reported responsibly is appreciated. Please avoid accessing, modifying, deleting, or disclosing data that you do not need to access to demonstrate the vulnerability.

Do not use vulnerabilities to disrupt BCAway, access other users' accounts or information, or interfere with school systems.
